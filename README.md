# DWCSS

**Code beyond the coder.**

DWCSS is a layout-first CSS system built for programmers, designers, and AI agents to work from the same stable structure.

The core idea is simple:

- `dw.css` owns layout, spacing, structure, and responsive behavior.
- Contracts own visual identity: color, type, background, radius, shadow, and motion.
- Examples should be readable by both humans and AI.
- Layout should be mathematical, durable, and portable across framework changes.

DWCSS is built to reduce CSS drift. When a template, visual builder, or framework produces tangled markup and styling, DWCSS gives that work a known landing structure before skin and brand choices are applied.

## Why It Exists

Modern websites are often maintained by a mix of humans, AI tools, old templates, new frameworks, and changing business needs. CSS drift happens when layout, color, typography, one-off fixes, and framework-specific habits all blend together.

DWCSS separates those concerns so code owners can keep structure stable while changing skins, templates, frameworks, or visual contracts.

## Free Core Boundary

The free version is intended to include:

- Core DWCSS layout primitives
- Starter visual contracts
- Small examples and documentation
- AI-readable structure notes
- Framework-neutral HTML/CSS patterns

Paid or Pro features should not be committed to this public repository unless intentionally released.

## Pro Boundary

Pro features may include the UI/UIX builder, generated contract tools, advanced repeaters, bridges, paid templates, and maintained Pro updates.
