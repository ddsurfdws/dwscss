# DWCSS Code Boundary

This project is the free/core showcase and should point toward:

`ddsurfdws/dwscss`

## Free/Core

Free/core files may include:

- Stable DWCSS layout primitives
- Starter contracts
- Free extensions
- Documentation examples
- Public showcase code

Important public files should carry a small `DWCSS Core` or `DWCSS Core Extension` header.

## Pro Preview

Free pages may mention Pro behavior when the page is teaching the idea, but the production Pro implementation belongs in:

`ddsurfdws/dwcsspaid`

Use `DWCSS Pro Preview` headers for public demonstration files that describe paid behavior without shipping the paid implementation.
