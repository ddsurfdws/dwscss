# DWCSS Extensions

Reusable free/core extensions.

- `dw-layout.css`: additional layout helpers
- `dw-data.css`: data grids, dashboards, dense tables, filters
- `dw-forms-advanced.css`: compact business form layout helpers
- `dw-navigation.css`: menu and navigation layout helpers
- `dw-overlays.css`: modals, drawers, and overlay shells
- `dw-states.css`: status and state helpers
- `dw-ai-driven.css`: public AI-readable pattern notes and Pro previews

Production Pro implementation source belongs in `ddsurfdws/dwcsspaid`.
