# DWCSS Core

This folder contains the free/core CSS package.

## Files

- `dw.css`: stable layout primitives and scoped base rules
- `contracts/`: default tokenized visual contract
- `contracts-red/`: starter red/cyan contract variant
- `extensions/`: reusable free extensions

## Boundary

This folder is intended for `ddsurfdws/dwscss`.

Paid builder source, Pro patterns, paid templates, and private bridges belong in `ddsurfdws/dwcsspaid`.
